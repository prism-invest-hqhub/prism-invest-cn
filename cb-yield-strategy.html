什么是到期收益率(YTM)？

YTM（Yield to Maturity）就是你买入可转债后，一直持有到期赎回，每年能赚多少百分比。它是衡量可转债"纯债价值"最核心的指标。

💡 简单说：YTM越高，说明你买得越便宜，持有到期越划算。YTM > 0 说明你持有到期不会亏钱。

📖 YTM计算公式详解

YTM的近似计算公式：

YTM ≈ [C + (F - P) / n] / [(F + P) / 2]

C = 每年票息，F = 到期赎回价，P = 买入价格，n = 剩余年限

举例：某转债价格95.5元，到期赎回价110元，剩余3.5年，每年票息1元：

  • YTM = [1 + (110-95.5)/3.5] / [(110+95.5)/2]
  • = [1 + 4.14] / 102.75
  • = 5.14 / 102.75 = 5.0%

YTM 5%意味着：就算正股不涨、不下修，你持有到期也能每年赚5%，比银行存款还高！

🎯 YTM实战筛选标准

YTM范围含义操作建议
YTM > 3%纯债价值高✅ 积极买入，安全垫厚
1% < YTM < 3%有一定保护🟡 可以持有，关注下修
0% < YTM < 1%保护较弱⚠️ 需正股上涨配合
YTM < 0%到期亏损❌ 不建议纯债持有

⚠️ YTM的3个常见误区

  • 误区1：YTM高就一定好 → 不一定。YTM高可能是因为价格跌了很多，要结合信用风险看
  • 误区2：YTM是保证收益 → YTM假设持有到期且公司不违约。如果公司违约，什么收益都是零
  • 误区3：所有转债都要看YTM → 偏股型转债（价格>130）YTM通常是负的，这很正常，它的价值在转股
